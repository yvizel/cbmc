Detailed Description

Traverses the clauses in order (wto) and resolving all predicates (symbols) that are not a head of a component (e.g.

a head of a loop). This is similar to variable elimination in SAT.

forall_exprt resolution_visitort::resolve_clauses ( const horn_clauset &  c1,
const horn_clauset &  c2 
)
inlineprivate

Assuming the following shapes: c1 := Sxx(ς) ∧ ς(COND1) ⇒ Syy(ς[update1]) c2 := Syy(ς) ∧ ς(COND2) ⇒ Szz(ς[update2]) In this case, Syy(ς) is eliminated and we use substitution for c2 such that it "operates" over ς[update1].

This results in: Sxx(ς) ∧ ς(COND1) ∧ ς[update1](COND2) ⇒ Szz(ς[update1][update2])
